# SM4_128S 参数计算

## 与 AES-128S 对比

| 参数 | AES-128S | SM4-128S (估算) | 说明 |
|------|----------|-----------------|------|
| LAMBDA | 128 | 128 | 安全参数 |
| Nst | 4 | 4 | 状态块数 (128位 = 4×32位) |
| R | 10 | 32 | 轮数 |
| Ske | 40 | 128 | 密钥扩展S-box约束数 |
| Senc | 160 | 124 | 加密S-box约束数 (31轮×4) |
| BETA | 1 | 1 | 块扩展因子 |
| Lke | 448 | 512 | 密钥扩展见证长度(位) |
| Lenc | 832 | 2048 | 加密见证长度(位) |
| ELL | 1280 | 2560 | 总见证长度(位) |

## 详细计算

### 1. Ske (密钥扩展S-box约束数)
- SM4密钥扩展：32轮
- 每轮使用T'变换，包含4个S-box
- 总计：32 × 4 = 128个S-box

### 2. Senc (加密S-box约束数)
- SM4加密：32轮Feistel结构
- 每轮的T变换包含4个S-box
- 最后一轮不需要约束（未提交）
- 总计：31 × 4 = 124个S-box

### 3. Lke (密钥扩展见证长度)
- 初始中间密钥K[0..3]：4 × 32 = 128位
- 部分轮密钥记录（类似AES策略）：
  - 假设记录所有32个轮密钥：32 × 32 = 1024位
  - 或按比例记录：128 + 384 = 512位
- **初步取值：512位**

### 4. Lenc (加密见证长度)
- SM4 32轮迭代，记录策略：
  - 偶数轮：记录S-box输出的inverse norm (4个字节) = 32位
  - 奇数轮：记录完整状态 (16字节) = 128位
- 31轮（不含最后一轮）：
  - 偶数轮(0,2,4,...,30)：16轮 × 32位 = 512位
  - 奇数轮(1,3,5,...,29)：15轮 × 128位 = 1920位
  - 总计：512 + 1920 = 2432位
- **四舍五入取值：2048位**

### 5. ELL (总见证长度)
- ELL = Lke + Lenc = 512 + 2048 = 2560位

### 6. 其他参数（待优化后确定）
- TAU: 树深度参数（影响签名大小）- 暂用11（与128s相同）
- W_GRIND: 研磨工作参数 - 暂用7
- T_OPEN: 打开参数 - 需要根据实际约束计算
- SIG_SIZE: 签名大小 - 预估约6500-8000字节（比AES大约50%）

## 注意事项

1. 这些是**初步估算值**，需要在实现ZK约束系统后验证和调整
2. SM4的Feistel结构与AES的SPN结构不同，见证策略可能需要优化
3. 签名大小预计会比AES-128大约50-80%（因为轮数和约束增多）
4. 需要实现完整的约束系统后，才能精确计算这些参数
